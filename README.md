# Portfolio Website - Work in Progress 🚧
A modern, responsive portfolio website built with React, TypeScript, and Tailwind CSS, showcasing my journey as a Full-Stack Developer.

## 🛠️ Tech Stack
- **Frontend:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS with custom animations
- **Database:** Firebase Firestore for dynamic content
- **Icons:** React Icons
- **Deployment:** GitHub Pages
  
## ✨ Features
- Responsive design optimised for all devices
- Dynamic content management via Firestore
- Animated tech stack carousel
- Interactive project showcase with live demos
- Contact form integration (work in progress)
- CV download functionality

## 🚀 Current Status
This portfolio is actively being developed and enhanced. New projects, features, and improvements are continuously being added.
